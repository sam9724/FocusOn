# Platform limitations and workarounds

| Platform / concern      | Limitation                                                                                                                                                                                                                                  | Recommended approach                                                                                                                                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| All PWAs                | JavaScript can be throttled or suspended; an offline service worker cannot schedule a reliable future notification after closure.                                                                                                           | Keep the app open for web alerts. Use a device alarm for critical deadlines, or the optional native wrapper. Remaining time is always recalculated on resume.                                                                             |
| iOS / iPadOS PWA        | Home-screen web push support does not provide this serverless app with an offline scheduling API. Notification construction and permissions vary.                                                                                           | Install through Safari for offline use; use Capacitor native local notifications for OS-scheduled alerts. No push server is added.                                                                                                        |
| Android native          | Android 13+ notification permission, Android 12+ exact-alarm access, battery restrictions, Doze, private space and user channel settings affect delivery. Doze can limit allow-while-idle frequency, so a short break alert may be delayed. | Enable app notifications and “Alarms & reminders” in OS Settings. Test on the actual device. The app uses two reserved schedule IDs and cancels them on pause/reset/changes. No alarm is treated as safety critical.                      |
| iOS native              | Notification permission, Focus modes, silent mode and OS policy govern alerts/vibration.                                                                                                                                                    | Enable local notifications in app Settings and iOS Settings. Validate foreground/background/locked-device delivery on hardware.                                                                                                           |
| iOS native cost/tooling | Xcode/macOS are vendor tooling; App Store distribution has membership costs. Free personal builds may require periodic reprovisioning.                                                                                                      | The free PWA is the standard distribution. Native source/configuration is optional; no App Store release is required.                                                                                                                     |
| Windows Tauri           | This scaffold has no native Windows scheduled-notification or tray daemon. Closing it stops JavaScript.                                                                                                                                     | Prefer installed PWA, or add a Windows OS notification adapter before promising closed-app alerts. Timer state resumes from IndexedDB.                                                                                                    |
| Sound and vibration     | Web Audio needs user activation; iOS browsers do not support the Vibration API. Native notification channel/user settings may override preferences.                                                                                         | The app primes audio on an interaction and uses native haptics when available. Use visual completion messages. Native background alert behavior needs device testing.                                                                     |
| Storage                 | Clearing browser data, private mode, quota/eviction, uninstall or origin changes can remove data. Persistent-storage requests may be denied.                                                                                                | Use regular JSON backups. Native and PWA installs have separate databases. Save errors are visible; retry after freeing space.                                                                                                            |
| Multi-window            | Web Locks support varies on old browsers; separate browser profiles have separate storage.                                                                                                                                                  | Use one window if locks are unsupported. Modern supported browsers block a second writer until the first closes.                                                                                                                          |
| Device clock            | Epoch timestamps follow wall-clock changes.                                                                                                                                                                                                 | Keep device date/time automatic. Time-zone changes only affect the local “done today” label, not the epoch deadline.                                                                                                                      |
| Updates                 | Offline use serves the last cached version; first-ever use requires network access.                                                                                                                                                         | Open once online and wait for offline readiness. Apply the update prompt when convenient. Task data survives app-shell updates.                                                                                                           |
| Export on mobile        | Browser download/share behavior varies; native WebViews may need an OS share/file adapter for a polished export workflow.                                                                                                                   | The JSON export uses a standard Blob download. Test it in the target wrapper; for mobile native distribution add Capacitor Filesystem/Share integration if the WebView does not save it. PWA export/import is the primary supported path. |
| Accessibility           | Automated scans do not prove full WCAG compliance or screen-reader usability.                                                                                                                                                               | Run the keyboard, zoom, VoiceOver and TalkBack checks in TESTING.md on target devices.                                                                                                                                                    |
| Lighthouse              | Current Lighthouse versions have removed the numeric PWA category.                                                                                                                                                                          | Audit Performance/Accessibility (target ≥90) and test manifest, offline reload, install behavior and icons separately.                                                                                                                    |

Native wrappers are configured for later builds. They are not shipped as signed or device-certified binaries. Browser audit results are scoped to the tested browser, viewport and build; they are not a guarantee for every device.
